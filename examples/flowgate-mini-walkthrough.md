# FlowGate mini walkthrough (Preflight lens)

This example **links** to the FlowGate portfolio repo — it does not duplicate requirements or code.

## What FlowGate demonstrates

[FlowGate](https://github.com/jah-guide/flowgate) is an SLA service-request workflow case study: structured intake → ops triage → manager → director approval, with live **On Track / At Risk / Breached** posture.

- **Live demo:** [jah-guide.github.io/flowgate](https://jah-guide.github.io/flowgate/)  
- **Repo:** [github.com/jah-guide/flowgate](https://github.com/jah-guide/flowgate)  
- **Printable case study:** [jah-guide profile case study](https://github.com/jah-guide/jah-guide/blob/main/case-studies/flowgate-case-study.md)

## Try Preflight on your own initiative

1. Clone [Preflight](https://github.com/jah-guide/preflight) skills into your agent.  
2. Run `requirements-engineer` on your problem statement.  
3. Scaffold with `analysis-docs-pack`.  
4. Gate implementation with `spec-driven-development`.  

Compare your `08` matrix structure to FlowGate’s — same pattern, your domain.
